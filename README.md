# Matteo Vaccargiu — personal academic website

Static website prepared for `https://matteovaccargiu.github.io`.

## Files
- `index.html` — homepage
- `publications.html` — complete publication list
- `styles.css` — visual design and responsive layout
- `assets/matteo.jpg` — profile photo
- `CV_Matteo_Vaccargiu.pdf` — CV linked from the navigation
- `.nojekyll` — tells GitHub Pages to serve the static site directly

## Publish on GitHub Pages
1. Create a **public** repository named exactly `matteovaccargiu.github.io` under the GitHub account `matteovaccargiu`.
2. Upload the **contents of this folder** to the root of the repository (do not upload the enclosing `matteo-site-draft` folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. The site will be available at `https://matteovaccargiu.github.io` after GitHub finishes the deployment.

## Local preview
Open `index.html` in a browser.
